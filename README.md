# WinOptimizer - Windows系统优化工具

> 一键优化Windows系统，让电脑焕发新生

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Windows-blue.svg)](https://www.microsoft.com/windows)

## 功能特性

- 🧹 **垃圾清理** - 一键清理系统垃圾，释放磁盘空间
- 🚀 **启动项管理** - 管理开机启动项，加速系统启动
- 📊 **系统信息** - 实时查看CPU、内存、磁盘使用情况
- 🌐 **网络优化** - 优化DNS，提升网络速度

## 快速开始

### 下载安装

从 [Releases](https://github.com/Pekmos/win-optimizer/releases) 下载最新版本

### 从源码运行

```bash
# 克隆仓库
git clone https://github.com/Pekmos/win-optimizer.git

# 安装依赖
pip install -r requirements.txt

# 运行
python src/main.py
```
